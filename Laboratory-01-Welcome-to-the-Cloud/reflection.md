# Reflection

Honestly, going into this lab, I thought it was just going to be "open a terminal, type some commands, done." Turns out there was more to it than I expected — especially the part where I kept losing my progress because the KillerCoda session would reset on me. Lesson learned: don't leave a playground idle for too long, and finish checkpoints in one sitting if possible.

Creating the user account and figuring out the difference between `adduser` and `useradd` was actually kind of interesting. I didn't realize how much detail goes into something as "simple" as making a new user — permissions, home directories, sudo access, all of that matters.

The system information part felt the most "real" to me, like I was actually poking around a real machine instead of just following a script. Seeing the actual CPU model, memory, and disk space made it feel less abstract.

Writing everything in Markdown was new-ish for me too. I've used it before for random notes, but never this deliberately — like it was actual professional documentation instead of just formatting text for fun.

Overall, this lab set the tone for what I'm expecting from this course: a lot of hands-on, sometimes frustrating, but ultimately useful practice. If this is just Mission 1, I'm curious (and a little nervous) about what's coming next.
