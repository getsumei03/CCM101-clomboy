# Cloud Provider Comparison

## Equivalent Services Table

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | EC2 (Elastic Compute Cloud) | Virtual Machines | Compute Engine |
| Storage | S3 (object storage), EBS (block storage) | Blob Storage, Managed Disks | Cloud Storage, Persistent Disk |
| Networking | VPC (Virtual Private Cloud) | Virtual Network (VNet) | VPC (Virtual Private Cloud) |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID (formerly Azure AD) | Cloud IAM |

## Guide Questions

**1. Which cloud provider offers the broadest range of services? Explain your answer.**

AWS is generally recognized as offering the broadest range of services, with hundreds of products spanning compute, storage, databases, machine learning, IoT, and more. It was the first major public cloud provider and has had the most time to build out a large ecosystem of specialized tools.

**2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?**

Microsoft Azure would be the best fit, since it integrates natively with Windows Server, Active Directory, Office 365, and .NET applications. Organizations already using Microsoft's ecosystem benefit from smoother licensing, identity management, and tooling compatibility.

**3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?**

Google Cloud Platform is widely recognized in this space. Google originally created Kubernetes and open-sourced it, and GCP offers strong AI/ML tooling through services like Vertex AI and TensorFlow integration.

**4. What similarities did you observe among the three cloud providers?**

All three providers offer equivalent core services in compute, storage, networking, and identity management, even though the names differ. They all follow a pay-as-you-go pricing model, operate global data center regions, and provide managed Kubernetes services for container orchestration.
