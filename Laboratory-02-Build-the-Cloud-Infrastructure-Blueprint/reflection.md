# Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?
I think compute is the most important cloud infrastructure component because it provides the processing power needed to run applications, services, and workloads. Without compute resources such as virtual machines, the other components would have limited purpose. Storage and networking are also important, but compute is what actually executes programs and allows cloud-based applications to function.

## 2. How does Linux support cloud computing?
Linux supports cloud computing because it is free, lightweight, reliable, and highly customizable. Its command-line interface makes it easy to manage servers and automate tasks using scripts. During this laboratory, I used Linux commands to inspect the system and understand its environment. Linux is also widely used for cloud virtual machines, including those provided by AWS, Azure, and Google Cloud.

## 3. Why is technical documentation important before deploying infrastructure?
Technical documentation is important because it provides a clear plan before infrastructure is actually deployed. Documenting the architecture, components, and decisions helps prevent mistakes and gives other engineers enough context to understand and maintain the system. It also improves accountability because there is a written record of what was planned and why specific infrastructure choices were made.
