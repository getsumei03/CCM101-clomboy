# AWS Research

## Brief Overview
Ang Amazon Web Services (AWS) ay yung cloud computing platform ng Amazon na nag-o-offer ng iba’t ibang online services tulad ng computing power, storage, at database management. Isa siya sa pinaka-malawak at pinaka-used na cloud providers sa buong mundo, kaya ginagamit siya ng iba’t ibang organizations — from small startups, big enterprises, hanggang government agencies. Isa rin sa reasons kung bakit trusted ang AWS ay dahil sa dami ng services na ino-offer nito, plus yung strong focus nila sa security ng customer data at applications.
## Global Infrastructure
Ang AWS ay may pinakamalawak na global infrastructure compared sa ibang cloud providers, na merong 39 geographic regions at 124 availability zones sa different parts ng mundo. Bawat region ay meron at least three availability zones, kaya kung magkaroon ng problem sa isang zone, hindi agad maaapektuhan yung buong system. With that, mas mabilis ang access ng users sa mga services at mas reliable din yung applications na naka-host sa AWS.
## Cloud Management Console
Ang AWS Management Console is basically a web-based interface kung saan you can access and manage your AWS resources gamit lang yung browser.

Meron din siyang central dashboard para makita mo agad yung resource usage, billing, and service health in one place.

Kasama rin yung IAM for managing user permissions and security, pati na rin yung cost and billing tools.

Super convenient siya for beginners kasi simple lang yung interface, pero okay din for experts since may CLI and SDK integration din.
## Four (4) Core Services
Four sa pinaka-common na core services ng AWS ay EC2, S3, RDS, at Lambda. Yung Amazon EC2 nagbibigay ng virtual servers na pwedeng gamitin for hosting applications or websites, and flexible din yung size depende sa kailangan ng user.

Yung Amazon S3 naman is a storage service for files, backups, and data na hindi naman kailangan naka-attach sa isang server. Basically, dito mo pwedeng i-store yung mga important files and data mo.

For databases, meron namang Amazon RDS na nagha-handle ng mga stuff like backups and maintenance automatically. So hindi mo na kailangan gawin lahat manually.

Then lastly, yung AWS Lambda is a serverless way to run code, so you only pay for the time na actually running yung function. Hindi mo na rin kailangan mag-set up or mag-maintain ng sariling server.
## Three (3) Advantages
Isa sa biggest advantages ng AWS ay yung dami ng services na ino-offer nito — meron itong more than 200 fully-featured services, from compute, storage, database, hanggang artificial intelligence. Kaya halos lahat ng kailangan ng isang business, pwede nang gawin within the same platform.

Pangalawa, gumagamit ito ng pay-as-you-go pricing model, meaning babayaran mo lang kung ano yung actual na nagamit mo. Hindi mo na kailangan mag-invest agad ng malaking amount para sa sariling hardware, kaya malaking help siya lalo na sa mga startups at small companies.

Panghuli, dahil sa malaking global infrastructure nito na may 39 regions at 124+ availability zones, maraming big companies, government agencies, at financial institutions ang gumagamit ng AWS. Reliable and secure din kasi siya, kaya trusted siya for different types of businesses.
## Typical Enterprise Use Cases
Malawak yung gamit ng AWS sa iba’t ibang enterprise scenarios. Maraming companies ang gumagamit nito para mag-host ng large websites or applications, lalo na yung mga kailangan ng scalability tulad ng e-commerce platforms.

Ginagamit din ang AWS for data backup and disaster recovery. Ini-store ng mga businesses yung important data nila sa S3 para may backup at protection kapag nagkaroon ng problem sa sariling infrastructure.

Bukod dito, ginagamit din ang AWS ng mga companies for big data analytics at machine learning models, gamit yung tools like SageMaker.

Panghuli, maraming enterprises ang nagta-transition from their own on-premises data centers to AWS bilang part ng cloud migration strategy nila. Nakakatulong ito para makatipid sa costs at magkaroon ng mas flexible na operations.
