# Cloud Platform Comparison

## Comparison Table

| Category | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008 |
| Compute Service | EC2 | Virtual Machines | Compute Engine |
| Storage Service | S3 | Blob Storage | Cloud Storage |
| Networking Service | VPC | Virtual Network (VNet) | Virtual Private Cloud (VPC) |
| Identity Service | IAM | Microsoft Entra ID (dating Azure AD) | Cloud IAM |
| Primary Strength | Pinakamalawak na service catalog | Microsoft ecosystem integration | Data analytics at AI |
| Ideal Organizations | Startups hanggang malalaking enterprise na kailangan ng malawak na options | Kumpanyang gumagamit na ng Microsoft products | Kumpanyang malakas sa data-driven o AI-based operations |

## Reflection Questions

**1. Which cloud provider offers the broadest range of services?**

Sa tatlong platforms, si AWS yung may pinaka-wide range of services, na may more than 200 fully-featured offerings from compute, storage, hanggang AI. Mas matagal na rin siya sa market since 2006, kaya mas marami na rin silang specialized services compared sa Azure at GCP.

**2. Which provider best integrates with Microsoft technologies?**

Si Microsoft Azure yung pinaka-best for companies na gumagamit na ng Microsoft products, since sila rin mismo yung gumawa nito. Directly integrated siya sa Windows Server, Microsoft 365, at Active Directory, kaya mas easy para sa businesses na mag-migrate to the cloud without changing their whole existing system.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**

For AI, si Google Cloud Platform yung mas known dahil sa tools like BigQuery at Vertex AI, and around 90% ng generative AI startups worldwide ay gumagamit ng GCP. For Kubernetes naman, strong din ang GCP since sila yung nag-start ng Kubernetes as an open-source project. Kaya solid din sila pagdating sa container orchestration gamit ang Google Kubernetes Engine (GKE).

**4. Which cloud platform would you personally choose and why?**

Personally, I would choose AWS kasi mas marami siyang services na pwedeng pagpilian, especially kung mag-start ako ng sariling project or business. Mas gusto ko rin yung flexibility niya since pwede akong pumili ng different services depending sa kailangan ng project. Plus, marami na ring resources and tutorials about AWS, so mas easy siyang aralin habang nag-i-improve pa ako.
