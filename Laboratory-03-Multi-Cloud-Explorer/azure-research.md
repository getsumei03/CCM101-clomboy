# Azure Research

## Brief Overview
Ang Microsoft Azure ay isang cloud computing platform na na-launch noong 2010, na naging malaking step mula sa traditional on-premises data centers papunta sa cloud computing. Sa ngayon, meron itong more than 200 products and services na supported ng global network na may 300+ highly secure datacenters sa more than 60 regions. Dahil sa lawak ng coverage nito, isa ang Azure sa may biggest cloud footprint compared sa ibang providers. Kaya rin itong ginagamit ng around 95% ng Fortune 500 companies for their enterprise-level operations.
## Global Infrastructure
Ang Azure ay may more than 70 regions sa buong mundo, kaya isa siya sa may pinaka-wide na coverage compared sa ibang cloud providers.

Bawat region ay may Availability Zones, kung saan bawat zone ay may at least three separate datacenters na may sariling power, cooling, at networking.

Dahil sa setup na ’to, kung magkaroon man ng problem sa isang zone or datacenter, hindi agad maaapektuhan yung buong system kasi tuloy pa rin gagana yung ibang zones.

Kaya mas reliable at mas mataas yung availability ng mga applications na naka-host sa Azure.
## Cloud Management Console
Ang Azure Portal ang management console ng Microsoft Azure — basically, web-based interface siya kung saan pwedeng gumawa, mag-manage, at mag-monitor ng Azure resources in one place.

Meron din itong customizable dashboard kung saan makikita yung overview ng mga services na ginagamit, tulad ng virtual machines, storage, at networks.

Kasama rin yung Cloud Shell para sa mga gustong gumamit ng command-line, so mas convenient siya para sa mga users na sanay sa ganung setup.

Meron din itong tools for cost tracking at role-based access control (RBAC), na nagko-control kung sino yung may access sa bawat resource.
## Four (4) Core Services
Four sa pinaka-common na core services ng Azure ay Virtual Machines, Blob Storage, Azure SQL Database, at Azure Functions. Yung Azure Virtual Machines nagbibigay ng sariling virtual servers na pwedeng i-configure depende sa kailangan, parang same concept lang din ng EC2 sa AWS.

Yung Azure Blob Storage naman is used for storing large amounts of data tulad ng images, videos, at backups. Maganda siya for files na hindi structured.

For databases, meron namang Azure SQL Database na nagha-handle automatically ng mga bagay like backups at patching, kaya less hassle na sa part ng user.

Then lastly, yung Azure Functions is a serverless compute service kung saan babayaran mo lang yung actual time na tumatakbo yung code. Hindi mo na rin kailangan mag-maintain ng sariling server.
## Three (3) Advantages
Isa sa biggest advantages ng Azure ay yung strong integration niya sa Microsoft ecosystem — from Windows Server, Microsoft 365, hanggang Active Directory. Kaya kung Microsoft products na yung gamit ng isang company, mas easy para sa kanila na gamitin din yung Azure.

Pangalawa, trusted din ang Azure ng maraming enterprises, kung saan 95% ng Fortune 500 companies ay gumagamit nito for their operations. May malaking team din sila ng security experts na patuloy na nagmo-monitor against cyberthreats.

Panghuli, strong din ang Azure pagdating sa artificial intelligence. Meron itong Azure AI Foundry na may more than 11,000 models, and ito rin yung exclusive cloud provider ni OpenAI. Kaya good option din siya for companies na nagde-develop ng AI-based applications.
## Typical Enterprise Use Cases
Malawak din yung gamit ng Azure sa iba’t ibang enterprise scenarios. Isa sa pinaka-common ay yung cloud migration ng mga companies na gumagamit na ng Windows Server, Microsoft 365, or Active Directory, kasi madali siyang i-integrate sa Microsoft ecosystem.

Ginagamit din yung Azure for hybrid cloud solutions, kung saan may parts ng infrastructure na nasa sariling data center pa rin habang yung iba naman ay gumagamit ng cloud services.

Bukod dito, maraming companies ang gumagamit ng Azure para sa pag-develop ng AI at machine learning applications, gamit yung mga tools like Azure AI Foundry.

Panghuli, ginagamit din siya for hosting mission-critical business applications tulad ng SAP at Databricks, lalo na yung mga applications na kailangan ng high availability and reliability.
