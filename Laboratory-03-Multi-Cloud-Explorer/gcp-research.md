# GCP Research

## Brief Overview
Ang Google Cloud Platform (GCP) ay yung cloud computing service ng Google, na gumagamit din ng same infrastructure na ginagamit sa mga products nila tulad ng Search, Gmail, at YouTube. Meron itong more than 100 products na sakop yung compute, storage, data analytics, at artificial intelligence. Isa sa biggest strengths ng GCP ay yung data analytics at AI capabilities nito, kaya maraming generative AI startups around the world ang gumagamit ng Google Cloud bilang platform nila.
## Global Infrastructure
Ang Google Cloud Platform ay may 43 global regions at more than 130 zones sa iba’t ibang parts ng mundo. Bawat region ay meron at least three zones, and bawat zone ay parang independent data center na separate sa isa’t isa.

Dahil sa setup na ’to, kung magkaroon ng problem sa isang zone, tuloy pa rin gagana yung system dahil may ibang zones na pwedeng mag-handle.

Isa pa sa biggest strengths ng GCP ay ginagamit niya yung same global network infrastructure na gamit din ng Google sa products like Search, Gmail, at YouTube.

Kaya dahil dito, mabilis and reliable yung performance ng GCP, especially for applications na kailangan ng stable connection and high availability.
## Cloud Management Console
Ang Google Cloud Console ang management console ng GCP — basically, web-based interface siya kung saan pwedeng i-manage lahat ng resources, na naka-organize under different “projects.”

Meron din itong customizable dashboard kung saan makikita yung resource usage, billing summary, at recent activity in one place.

Kasama rin yung Cloud Shell para sa mga gustong gumamit ng command-line, so mas convenient siya for users na sanay sa ganitong setup.

Meron din itong IAM tools para ma-manage yung access at security ng bawat resource.
## Four (4) Core Services
Four sa pinaka-common na core services ng GCP ay Compute Engine, Cloud Storage, Cloud SQL, at BigQuery. Yung Compute Engine nagbibigay ng virtual machines na pwedeng gamitin for hosting applications, basically same concept din ng EC2 sa AWS.

Yung Cloud Storage naman is used for storing files, backups, and other unstructured data. So dito pwedeng ilagay yung mga malaking files na kailangan i-store online.

For databases, meron namang Cloud SQL na nagha-handle ng relational databases like MySQL at PostgreSQL, kaya mas convenient siya kaysa ikaw mismo ang mag-manage ng lahat.

Then lastly, yung BigQuery is a serverless data warehouse na kayang mag-analyze ng super laki na datasets gamit SQL queries. Kaya ginagamit siya ng maraming businesses na kailangan ng fast and efficient data analytics.
## Three (3) Advantages
Isa sa biggest advantages ng GCP ay yung strength nito sa data analytics at artificial intelligence. Halos 90% ng mga generative AI startups around the world ay gumagamit ng Google Cloud, gamit yung mga tools like BigQuery na kayang mag-analyze ng super large datasets in just a few seconds.

Pangalawa, known din ang GCP sa simple and transparent pricing. Gumagamit ito ng pay-as-you-go model with per-second billing, so babayaran mo lang yung actual time na ginamit mo yung resources.

Panghuli, dahil same global infrastructure yung ginagamit ng GCP na supported din ng Google products like Search at YouTube, mataas yung reliability and speed nito, especially for applications na maraming users.
## Typical Enterprise Use Cases
Malawak din yung gamit ng GCP sa iba’t ibang enterprise scenarios. Isa sa pinaka-common ay yung big data analytics, kung saan ginagamit ng mga companies yung BigQuery para mag-analyze ng malaking amount ng customer data or business metrics.

Marami rin gumagamit ng GCP for AI and machine learning applications, gamit yung mga tools like Vertex AI at TensorFlow.

Bukod dito, ginagamit din yung GCP for hosting websites and applications through Compute Engine or Cloud Run, especially yung mga apps na kailangan ng automatic scaling.

Panghuli, ginagamit din siya ng maraming companies sa media and entertainment industry through Cloud CDN para mas mabilis ma-deliver yung content sa customers kahit nasa iba’t ibang parts ng mundo.
